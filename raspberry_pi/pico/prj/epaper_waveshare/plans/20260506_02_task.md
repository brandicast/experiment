# Enable WiFi Provisioning

The purpose of this task is to enable Pico about the connect to WiFi.

## Requirements

- On Pico boot up.  Check if there is any WiFi configuration.  If yes, try to connect to WiFi.  If not, start WiFi provisioning process.
- Try to connect to WiFi for 5 times.  Each time can have timeout for 30 seconds.
- Print the connecting status on the scree during each steps.
- When it goes into WiFi provisioning process, blink the onboard LED rapidly to indicate it is entering the WiFi provisioning mode. 
- Once any remote client device connects to Pico thru Wifi, let client device to share the WiFi configuration to Pico.  Pico shall save the connection information under folder ./configs.  Please suggest the sharing method.
